Sign in

This page talks to your local server with your bearer token (the same ADAM_TOKEN the Operator Console uses). It is stored on this device only.

Easiest way in: on your computer, start Adam with the Start Adam launcher (scripts\start-adam.ps1) — it opens you already signed in, so you won't see this box. To copy the token by hand, run scripts\copy-token.ps1 and paste it above.

Adam runs on your PC. This puts the whole assistant — voice included — on your phone, talking to that same PC. On the same Wi-Fi it works right away; with Tailscale it works anywhere you go. Nothing is published to the internet, and the sign-in code below is drawn on your own machine.

Make it an app (add to home screen)

Once Adam is open on your phone, add it to the home screen so it gets its own icon and opens full-screen like a normal app.

  1. iPhone (Safari)

    Tap Share (the square with an up-arrow) → Add to Home Screen → Add.

  2. Android (Chrome)

    Tap the ⋮ menu → Add to Home screen / Install app.

The first time you open it from the home-screen icon it may ask for your access token again — an installed app gets its own private storage. Turn on Cautious mode above, tap Show token QR, and scan that code with your Camera; it will offer to Copy the token. Paste it into the app's token box and you're in for good.
