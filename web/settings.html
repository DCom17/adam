Back up your data

Download everything Adam can't rebuild — your trackers, sessions and settings — as a single file. Adam keeps a copy of each file before it changes it, but that doesn't help if the machine itself is gone. Your API keys are deliberately left out, so the file is safe to keep in Drive or on a USB stick.
