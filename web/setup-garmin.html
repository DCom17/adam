Garmin Sync

Heads up — this is unofficial. Garmin has no public app connection, so Adam signs in with your Garmin email and password (kept only on this computer, never sent anywhere else) and reads the same data the Garmin app shows. Garmin can change things and break this at any time. It only ever reads your data into your private Health Tracker.
One-time: Adam needs a small sync library on this computer. Tap Install sync library below — no terminal needed. (If it ever fails, you can run pip install garminconnect in the Adam folder instead.)
